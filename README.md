# Ticket Tracker App (from scratch - NO AI CODING)

## What It Does?

- This app is a platform where a user can submit a ticket regarding technical issues.
- This app stores various tickets with different types of info such as names of clients, types of issues, and more. 

## A "Planned Feature" List

- submit tickets
- status updates
- filter
- search
- login
- roles

### Notes
1. The rule: a page should have only one <main>. It marks the main content of the whole page. Inside it, you use <section> to split that content into parts.

2. Semantics Elements of HTML

- Examples of non-semantic elements: <div> and <span> - Tells nothing about its content.

- Examples of semantic elements: <img>, <table>, and <article> - Clearly defines its content.
